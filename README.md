# AI-IoT-Network-Health-Monitor
An AI-powered IoT network monitoring system that uses ESP32 devices to collect real-time network metrics, analyzes packet loss and latency, predicts future network degradation using Machine Learning, visualizes network health through an interactive dashboard, and supports cloud integration with automated alerts for proactive network management.

Project Description :
AI-Driven IoT-Based Real-Time Network Health Monitoring and Packet Loss Prediction System is an intelligent network monitoring solution designed to continuously monitor the health of IoT-based wireless networks. The system uses multiple ESP32 devices as IoT nodes to transmit heartbeat packets over a Wi-Fi network using the MQTT protocol. A Python-based backend collects these packets, analyzes key network performance metrics such as packet loss, latency, jitter, throughput, and signal strength (RSSI), and stores the data for real-time and historical analysis.
The collected network data is processed using Machine Learning algorithms to identify patterns and predict future network degradation before failures occur. A live Streamlit dashboard visualizes network health, connected devices, packet statistics, and AI-generated predictions, enabling proactive monitoring and decision-making. The system can also generate alerts through email or Telegram when network performance falls below predefined thresholds.
The project follows a modular architecture with separate components for IoT firmware, communication, backend processing, database management, AI prediction, dashboard visualization, alerting, and optional cloud integration using Firebase or AWS IoT Core. Designed with scalability and maintainability in mind, the system can be extended to smart homes, industrial IoT, healthcare, smart cities, and campus network monitoring applications.
By combining IoT, Computer Networks, Artificial Intelligence, Data Analytics, and Cloud Computing, this project demonstrates how intelligent monitoring systems can improve network reliability, reduce downtime, and enable predictive maintenance in modern connected environments.
